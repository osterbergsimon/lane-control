# pi

Status: untested

No adapter yet, not installed. Orca 1.4.250 lists two agents here: `pi` (command `pi`) and `omp` (command `omp`,
"oh-my-pi"), which reads pi's session folders as well as its own. Orca's worker-start accepts `--model` only for
OMP; its other paths pass a model flag (`--model`) and an effort flag (`--thinking`) to `omp`. So the OMP agent is
oh-my-pi, a separate program built on pi, not pi itself; which of the two to trial, and how it is installed, is the
trial's first step.
